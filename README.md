# java-lotto-precourse

## 구현 기능 목록

### 0. 모든 메세지 및 순위 enum 열거형  `Message`, `RankPrize`
  - [X] 에러 매세지 
  - [X] 출력 메세지 
  - [X] 순위 및 당첨 금액 

### 1. 입력 및 검증  `InputView`, `PurchaseAmount`
  - [X] 로또 구입 금액을 입력 받는다. 
  - [X] 구입 금액이 유효한지 확인한다. 
  - [X] 구입 금액에 맞는 로또 구매 개수를 계산한다.

### 2. 로또 자동 발행   `Lotto`, `LottoGenerator`
  - [X] 구매 개수만큼 로또를 자동 발행한다.
  - [X] 1~45사이의 숫자 중 중복없이 6개의 숫자를 생성한다.
  - [X] 로또 번호는 오름차순으로 정렬된다.
  - [X] 발행된 로또를 출력한다.

### 3. 당첨 번호와 보너스 번호 입력 및 검증   `WinningNumber`, `BonusNumber`
  - [X] 당첨 번호 6개를 입력 받는다.
  - [X] 쉼표(,) 기준으로 구분한다.
  - [X] 당첨 번호가 유효한지 확인한다.
  - [X] 보너스 번호를 입력 받는다.
  - [X] 보너스 번호가 유효한지 확인한다.

### 4. 당첨 결과 및 수익률 계산   `LottoResult`
  - [X] 발행한 로또와 (당첨 번호 + 보너스 번호)가 일치하는지 확인한다.
  - [X] 각 순위별 당첨 개수를 저장한다.
  - [X] 수익률을 계산한다.

### 5. 당첨 결과 출력    `OutputView`
  - [X] 당첨 내역을 출력한다.
  - [X] 수익률을 출력한다. (소수점 둘째 자리에서 반올림)

### 6. 예외 처리
- 모든 예외 발생 메세지는 [ERROR]로 시작한다.
- 예외 발생 시 해당 부분부터 다시 입력 받는다.
  - [X] 구입 금액이 숫자가 아닌 경우
  - [X] 구입 금액이 양수가 아닌 경우
  - [X] 구입 금액이 1000원으로 나누어 떨어지지 않는 경우
  - [X] 당첨 번호가 6개가 아닌 경우
  - [X] 당첨 번호가 중복되는 경우
  - [X] 당첨 번호가 1~45 범위가 아닌 경우
  - [X] 보너스 번호가 당첨 번호와 중복되는 경우
  - [X] 보너스 번호가 1~45 범위가 아닌 경우 

### 7. 로또 컨트롤러    `LottoController`
  - [X] 잘못된 입력이 들어오면 다시 입력
